# 语法参考

> 迁移自 Covariant Script Wiki (STD201201)

## 2.1 语句（statement）

以换行符结束的一行代码称为语句。任意语句都可以将分号 `;` 作为终结符。

```
语句1; 语句2; 语句3
```

## 2.2 预处理（preprocessor）

### 注释

```
语句 # 注释
```
任意 `#` 之后的内容均视为注释。

### 行连接

```
@begin
  语句
@end
```

在 `@begin` 和 `@end` 之间的代码将视为一行语句，所有换行符都将会被忽略。

### 字符集

```
@charset: 字符集
```

| 编码 | 字符集 |
|------|--------|
| ASCII 纯文本 | `ascii` |
| UTF-8 简体中文 | `utf-8` |
| GBK 简体中文 | `gbk` |

当选择 Unicode 中文编码(UTF-8/GBK)时，可以使用简体中文作为标识符。

## 2.3 关键字（keyword）

Covariant Script 的关键字分为两种：

- **强制型关键字**：编译器遇到这个词即视为使用这个语法标识符
- **标识型关键字**：仅在符合语法时编译器才会将其视为语法标识符

### 强制型关键字

| 关键字 | 含义 |
|--------|------|
| `and` | 与运算符 |
| `or` | 或运算符 |
| `not` | 非运算符 |
| `typeid` | 类型信息 |
| `new` | 新建栈对象 |
| `null` | 空指针 |
| `local` | 本地作用域 |
| `global` | 全局作用域 |
| `true` | 逻辑真 |
| `false` | 逻辑假 |
| `gcnew` | 新建堆对象 |

### 标识型关键字 (190501)

| 关键字 | 含义 |
|--------|------|
| `import` / `as` | 引入包 |
| `package` | 包定义 |
| `namespace` | 声明名称空间 |
| `using` | 引入名称空间 |
| `struct` / `class` | 声明结构体 |
| `extends` | 继承结构体 |
| `block` | 声明语句块 |
| `var` | 声明变量 |
| `constant` | 声明常量 |
| `if` / `else` / `switch` / `case` / `default` | 分支语句 |
| `end` | 结束语句块 |
| `while` / `loop` / `until` / `for` / `foreach` / `in` / `do` | 循环语句 |
| `break` / `continue` | 循环控制 |
| `function` / `override` | 函数声明 |
| `return` | 返回语句 |
| `try` / `catch` / `throw` | 异常处理 |

> 在 190501 前的标准中，标识性关键字也属于强制型关键字。

## 2.4 模块（module）

### 引入模块

```
import Package名, Package名...
```

引入一个或多个 Package。

```
import Package名[(.名称空间名)...] as Package别名
```

引入一个 Package 或 Package 内的名称空间，并设置别名。

引入的 Package 可以是 `*.csp` 文件（CovScript 包）或者是 `*.cse` 文件（CovScript 扩展）。当两者同时存在时会优先引入 `*.csp` 文件。

### 声明模块

```
package Package名
```

包名应和文件名相同。

## 2.5 变量（variable）

### 2.5.1 定义

```
var 变量名 = 表达式, 变量名 = 表达式...
```

定义一个或多个变量，初始值为表达式的值。

```
constant 常量名 = 表达式, 常量名 = 表达式...
```

**[慎用]** 定义一个或多个常量。常量类似于 C++ 中的 `constexpr`，实际上**仅存在于编译期**。

### 2.5.2 在栈上新建对象

```
new 类型
```

在栈上新建一个指定类型的对象，遵从 RAII 原则自动回收。

### 2.5.3 在堆上新建对象

```
gcnew 类型
```

在堆上新建一个指定类型的对象，由垃圾回收器自动回收。

## 2.6 表达式（expression）

### 一元运算符

| 运算符 | 优先级 | 功能 |
|--------|--------|------|
| `- 表达式` | 10 | 数学取反 |
| `* 表达式` | 11 | 指针解引用 |
| `typeid 表达式` | 14 | 运行时类型信息 |
| `new 表达式` | 14 | 新建对象 |
| `gcnew 表达式` | 14 | 新建堆对象 |
| `! 表达式` | 8 | 非运算 |
| `++ 表达式` / `表达式 ++` | 13 | 递增 |
| `-- 表达式` / `表达式 --` | 13 | 递减 |

### 二元运算符（右结合）

| 运算符 | 优先级 | 功能 |
|--------|--------|------|
| `+` `-` | 10 | 加法/拼接，减法 |
| `*` `/` | 11 | 乘法，除法 |
| `%` `^` | 12 | 取余，幂运算 |
| `.` `->` | 15 | 成员访问，指针成员访问 |
| `<` `>` `<=` `>=` | 9 | 比较 |
| `==` `!=` | 9 | 相等/不相等 |
| `&&` / `and` | 7 | 逻辑与（短路） |
| `||` / `or` | 6 | 逻辑或（短路） |

### 二元运算符（左结合）

| 运算符 | 优先级 | 功能 |
|--------|--------|------|
| `=` | 1 | 赋值 |
| `+=` `-=` `*=` `/=` `%=` `^=` | 1 | 复合赋值 |

### 特殊运算符

| 运算符 | 优先级 | 功能 |
|--------|--------|------|
| `表达式, 表达式` | 0 | 逗号表达式 |
| `表达式 : 表达式` | 4 | 建立映射 |
| `表达式(参数列表)` | 15 | 函数调用 |
| `表达式[表达式]` | 15 | 下标访问 |
| `表达式...` | 20 | 数组展开 |
| `(表达式)` | — | 子表达式 |

### 条件表达式

```
逻辑表达式 ? 表达式1 : 表达式2
```

### 结构化绑定

```
(表达式1, 表达式2...) = 表达式3
```

结构化绑定可以嵌套，也可用于变量声明：
```
var (a, (b, c)) = test(...)
```

## 2.7 作用域和名称空间

### 临时作用域

```
block
  语句块
end
```

### 名称空间

```
namespace 名称空间名
  语句块
end
```

### 名称查找

| 写法 | 含义 |
|------|------|
| `变量名` | 从最上层作用域向下查找 |
| `local.变量名` | 当前作用域 |
| `global.变量名` | 全局作用域 |
| `名称空间名.变量名` | 名称空间内查找 |
| `变量名.变量名` | 结构体或扩展成员 |

对于结构体或扩展，`char.isspace(ch)` 等价于 `ch.isspace()`。
